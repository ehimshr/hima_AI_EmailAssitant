1. Technical Architecture
    Multi-Agent System : LangGraph
    Language Models : Claude
    Email Template Engine : LangChain + Function Calling
    User Profile Store : JSON
    Web Interface : Streamlit
    Memory Layer : LangGraph Memory
    Control Plane (MCP) : LangSmith


Agent Name : Function
Input Parsing Agent : Validates prompt, extracts intent, recipient, tone, constraints
Intent Detection Agent : Classifi es intent: outreach, follow-up, apology, info, etc.
Tone Stylist Agent : Adjusts tone (formal, friendly, assertive, etc.) using tokenized prompts
Draft Writer Agent : Generates main body text with structure and clarity
Personalization Agent : Injects user profi le data and prior messages
Review & Validator Agent : Checks grammar, tone alignment, and ensures contextual coherence
Routing & Memory Agent : Manages fallback fl ow, logs drafts, and stores profi le memory
